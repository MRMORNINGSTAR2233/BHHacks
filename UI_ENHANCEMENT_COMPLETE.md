### 🎮 **Game Mode** - Interactive Horror Game

**Visual Design:**
- 🌑 Dark, immersive game interface
- ⚡ Neon accents and glowing effects
- 🎯 Sans-serif typography (modern/tech)
- 📊 Three-column layout with HUD
- 🎮 Game-like UI elements
- 💀 Dark theme with atmospheric effects

**Game Mechanics:**

#### **Health System** ❤️
- Real-time health bar (0-100%)
- Color-coded: Green → Yellow → Orange → Red
- Critical warnings when low
- Affected by story choices

#### **Sanity System** 🧠
- Mental health tracking (0-100%)
- Decreases with fear and horror
- Affects decision-making
- Visual feedback

#### **Fear Level** 💀
- Dynamic fear tracking (0-100%)
- Increases with story progression
- Affects music intensity
- Animated pulsing effect

#### **Inventory System** 🎒
- Collect items from story
- 10-item capacity
- Use items to affect outcomes
- Visual item display with icons
- Usable/non-usable items

#### **Game HUD**
- Top-left: Health/Sanity/Fear bars
- Left sidebar: Inventory
- Bottom-left: Story timeline
- Save game button
- Real-time stat updates

**Perfect For:**
- Users who want an interactive game
- Gamification and progression
- Competitive/achievement-focused players
